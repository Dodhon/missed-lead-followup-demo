Your project sounds like a workflow problem more than a giant software build. I would handle it in three steps:

1. Map the current lead path: source, owner, status, response time, and booking outcome.
2. Build the first working queue: open leads, stale leads, quote follow-ups, owner, next step, and draft messages.
3. Add a simple report: what is open, what is overdue, what got booked, and what needs a human decision.

I built a demo for this exact pattern so you can see the type of output I mean. It uses fictional data, but the structure is ready to adapt to a real business stack.
